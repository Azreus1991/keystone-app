# Keystone

**Your Personal Sovereign Life OS** — a private, local-first command center for your whole life, with an AI concierge.

## Download
Grab the latest installer from the **[Releases](../../releases/latest)** page → `Keystone_0.1.0_x64-setup.exe`.

### First run
1. Windows SmartScreen will warn (it is not code-signed yet) → click **More info → Run anyway**.
2. For the local AI, install [Ollama](https://ollama.com) and run `ollama pull qwen2.5:14b`.

Everything runs on your machine. Nothing leaves it.
